How the System Works
The program has a simple menu that allows the user to choose what they want to do. The user can add a new study session, view all the sessions, search for a particular subject, view study statistics, or save the information and exit the program.
When adding a session, the program asks for the subject, topic, date, and study time. I also added validation so that the user cannot enter a zero or negative study time.
The program also classifies each study session as Short, Medium, or Long depending on how many minutes the student studied. This makes it easier to understand the length of each session.
The search option allows the student to search for a subject and see how much total time they have spent studying it. The search works even if the student uses capital or small letters.
The statistics section shows the total study time, the study time for each subject, the subject with the least study time, and the longest study session.
